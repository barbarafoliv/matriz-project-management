Problem:
A created task only appears in the listing after reloading the page.

Steps to reproduce:
1. Open a project with permission to create tasks.
2. Fill in the form with a valid title.
3. Submit the form.
4. Observe the listing.
5. Reload the page.

Expected result:
The task appears in the listing after the creation confirmation.

Observed result:
The interface confirms the creation, but the listing remains unchanged.
After reloading, the task appears.

Frequency:
The problem occurs on every attempt made.
