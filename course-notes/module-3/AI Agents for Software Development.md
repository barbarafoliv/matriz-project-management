# AI Agents for Software Development

This page brings together Artificial Intelligence tools with agentic capabilities that can support the different phases of software development, from requirements analysis to implementation, testing, documentation and maintenance.

The tools presented offer free plans, open source versions or the option to run locally.

## 1. AI agents for programming

- **Cline** — Open source agent that can analyse projects, generate and change code, run commands and automate tasks directly in the editor or terminal. The tool is free, but some AI models may have costs.
- **Cursor** — Development environment with agents that can analyse code, implement features and fix errors. The Agent mode in the editor has limited free use; the Cloud Agents available at the link require a paid plan.
- **GitHub Copilot** — Programming assistant integrated into different IDEs, with code generation, chat and agent mode features. Offers a free plan with usage limits.
- **Google Antigravity** — Agent-oriented development platform, able to implement features, run tasks and support software validation. Includes a free individual plan with limits.
- **OpenCode** — Open source programming agent for the terminal, editor and desktop. Supports different AI models, including free and local options.

## 2. Open source agents and local execution

- **Aider** — AI-assisted development tool for the terminal, with Git integration, code changes and test execution.
- **Goose** — Open source agent that automates programming tasks, works with external tools and runs workflows on the computer.
- **OpenHands** — Open source platform for running and coordinating software development agents, with local execution options and repository integration.

## 3. Frameworks for multi-agent systems

- **CrewAI** — Open source framework for building systems with several specialised agents that collaborate on tasks. It lets you define roles, goals and workflows, and is particularly useful for experimenting with multi-agent architectures. It also has a free plan on its platform with usage limits.

## 4. Complementary tools

- **Ollama** — Runs AI models locally and integrates them with some of the agents above. It is an alternative for trying models without necessarily depending on paid APIs, as long as the computer has enough resources.

## Important recommendations

- Check the limits and any costs of the AI models used.
- Use version control (Git) to track the changes made by agents.
- Review and validate generated code before integrating it into a project.
- Run tests to check that the requirements are met.
- Don't share credentials, API keys or confidential information with external tools.
- Check the permissions granted to agents, especially for running commands and changing files.

**Suggestion:** try using an agent to implement a simple feature, generate tests and document the code. Then analyse the quality of the changes produced and compare the results with the defined requirements.

**Note:** the tools and their free plans may change. Information checked in October 2026.
