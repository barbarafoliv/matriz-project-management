# Module 1 - Introduction & AI Development Mindset

2026-10-14

## Software engineer responsibilities

- Define objectives
- Structure context
- Delegate tasks
- Validate results
- Review decisions
- Integrate tools
- Coordinate agents

## Context window

The **context window** is the limit of tokens that the model can consider in an execution.

The context can include:

- System and project instructions
- User request and conversation history
- Provided code and documentation
- Information retrieved by RAG
- Tool results

## CLAUDE.md

CLAUDE.md is a text file, usually in Markdown, that explains to the AI how to work on that project. It serves as an onboarding guide for a new team member.

It can indicate:

- The purpose of the project and its architecture
- The coding and file organization conventions
- The commands to install dependencies, compile, and test
- The restrictions to be respected in the changes
- The work validation criteria
