# ROLE
Act as a Senior UI/UX Designer and Frontend Engineer.

# GOAL
Create an interface prototype for the Matriz application, intended for managing projects and tasks.

# CONTEXT
Analyse the existing requirements, User Stories and constraints in the project.

Consider the architecture, the technology stack and the API contracts, if they are already defined.

# CONSTRAINTS
- Consider only MVP features.
- Favour a simple and intuitive interface.
- Use reusable components.
- Ensure responsiveness and accessibility.
- Don't invent features that haven't been approved.
- Don't introduce new dependencies without justification.

# TASKS
1. Identify the main screens and workflows.
2. Propose the navigation structure.
3. Define the necessary components.
4. Create a prototype of the dashboard.
5. Include loading, empty and error states.
6. Use mock data, identified as such.

# OUTPUT
- Screen structure.
- Reusable components.
- Interface prototype.
- UI/UX decisions and their justification.
- Assumptions and pending questions.

# VALIDATION
Check the coverage of the requirements, visual consistency, responsiveness and accessibility.

Don't change existing files without approval.
