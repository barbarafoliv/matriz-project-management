# Deploying the Matriz Project: Free Platforms

Dear trainees,

Following the last class, here are the recommended platforms for deploying the Matriz project, so the application is available online, at a public address with HTTPS, at no cost.

## Option 1: Render

https://render.com

Hosts web applications, including the frontend and backend, with GitHub integration and automatic deployment from the repository.

## Option 2: Render + Neon

- **Render:** https://render.com, hosting for the frontend and backend.
- **Neon:** https://neon.tech, a PostgreSQL database in the cloud.

This second option is especially suited to projects that need a persistent database.

Both options have free plans, with usage limits. Render also provides a free public subdomain.

I recommend that you explore one of these options and, if possible, put Matriz online, so you can demonstrate the application during the final presentation.
